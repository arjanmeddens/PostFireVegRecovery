# PostFireVegRecovery
This repository includes, code, data and figures from a NWCASC-funded and JFSP project related to quantifying post-fire vegetation recovery. 

Citation of the JFSP final report: 
Franz, M.C. and Meddens, A.J.H. (2025). Using NAIP DAP and Landsat time series data to quantify post-fire vegetation recovery. Joint Fire Science Program Final Report:  JFSP PROJECT ID: 23-1-01-6, 35pp.

Citation of journal article in review:
Franz, M., Meddens, A.J.H., Andrus R.A., Celebrezze J., Steen-Adams M. (in review). Disentangling spectral recovery patterns of mixed-conifer forests in the Inland Northwest. Prospective journals: Fire Ecology.
